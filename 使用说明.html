快速开始

1
双击 start.bat 启动
脚本会自动检查 Python 环境和依赖包，首次运行会询问是否安装依赖（输入 y 确认）
2
打开微信窗口
确保微信已登录并显示在桌面上（不要最小化），程序会自动定位窗口
3
点击「开始监控」
程序会分步初始化各模块（约5秒），日志区会逐步显示加载进度
4
查看实时消息
切换到「实时消息」标签页，新消息会以彩色卡片形式出现在最上方

红点监控机制

红点监控是本工具的核心功能，自动检测微信左侧栏的未读消息红点：

检测流程

每3秒扫描左侧栏
    ↓
模板匹配（优先）→ HSV 6特征检测（兜底）
    ↓
OCR 识别侧边栏文字
    ↓
红点Y坐标 ↔ 联系人名Y坐标 匹配（±60像素）
    ↓
切换到未读联系人 → 提取消息 → 切回原窗口
    ↓
60秒冷却（防止重复切换）

HSV 6大特征

特征阈值说明
颜色#FA5151微信红点精确颜色
面积100-3000 px²排除头像和图标
圆形度> 0.5排除非圆形红色元素
位置x > 35% 宽度排除左侧头像区
内部白字white_ratio > 0.03必须有白色数字
排序按 white_ratio 降序优先处理数字最多的红点
模板匹配：首次运行时自动从HSV检测结果中截取红点模板并保存，后续运行优先使用模板匹配，精度更高。

配置文件说明

所有配置集中在 config.yaml，修改后保存，在设置页点击「保存设置」生效。

关键配置项

# 自动回复（默认关闭）
auto_reply:
  enabled: false
  send_delay: 0.5

# 红点监控
red_dot_monitor:
  enabled: true
  cooldown_seconds: 15
  red_min_area: 150
  red_max_area: 5000

# LLM 配置
llm:
  provider: custom
  base_url: https://dashscope.aliyuncs.com/compatible-mode
  api_key: your-api-key
  model: qwen3.7-flash-2026-07-15

# 联系人过滤（黑名单默认含公众号/服务号等）
contacts_filter:
  whitelist: []
  blacklist:
    - 公众号
    - 服务号
    - 订阅号
    - 文件传输助手

# Obsidian 同步
obsidian:
  mode: file
  vault_path: E:\Obsidian\file\诺亚
  folder: 微信消息
  auto_sync: true

常见问题

Q: 启动时提示「未找到微信窗口」

确保微信已登录且窗口显示在桌面（非最小化），窗口标题不含「AI」或「助手」。

Q: OCR 识别不到文字

1. 检查微信窗口是否被遮挡
2. 在设置页调整 OCR 缩放比例（建议 0.5-0.85）
3. 使用「窗口校准」功能手动框选聊天区域
4. 查看 DPI 缩放设置（推荐 100% 或 125%）

Q: 红点检测不到未读消息

1. 查看 debug 目录下的 sidebar_capture.png 和 red_dot_mask.png
2. 确认红点颜色为 #FA5151（微信标准红）
3. 调整 red_min_area 和 red_max_area 参数
4. 首次运行会自动截取红点模板，后续精度会提升

Q: 自动回复误触发

自动回复默认关闭。如需开启，请在「回复设置」标签页手动开启，并配置好联系人角色。建议先用「测试OCR」验证识别准确性。

Q: 首次启动很慢

首次启动需要初始化 PaddleOCR 模型和 LLM 客户端，约5-10秒。程序会分步加载并显示进度日志，属正常现象。

Q: 导出的 CSV 乱码

用记事本打开 CSV 另存为「UTF-8 with BOM」编码，或直接用 Excel 打开并选择「UTF-8」编码导入。
