Features

核心功能

从截图到识别、从提取到回复，全自动一条龙

🔴

红点监控

自动扫描微信左侧栏未读红点，识别后切换到对应联系人，提取完自动切回原窗口。

  • 模板匹配 + HSV 6特征双重检测
  • 自动学习红点模板，越用越准
  • 冷却机制防止重复切换
🔍

OCR 识别

基于 PaddleOCR 的中英文混合识别，精准区分自己/对方的消息气泡。

  • 帧间差异 + pHash 增量检测
  • 底部区域裁剪减少无效识别
  • 稳定帧过滤避免重复解析
🧠

AI 信息提取

接入通义千问大模型，自动分析消息内容并提取关键信息。

  • 消息分类 / 紧急程度 / 摘要
  • 待办事项与情绪分析
  • 关键词 + 正则自定义规则
🤖

AI 自动回复

多角色回复风格：技术顾问、商务伙伴、可爱朋友、段子手，按联系人分配。

  • 前 10 次 AI 学习，之后纯规则模式
  • 可配置发送延迟防风控
  • 默认关闭，按需开启
🗄️

数据管理

本地 SQLite 存储，消息自动导出，支持历史搜索与日报周报。

  • CSV / JSON 双格式导出
  • 关键词 + 联系人 + 日期搜索
  • HTML 格式日报 / 周报
📓

Obsidian 同步

将提取的消息同步到 Obsidian 知识库，按联系人和日期组织笔记。

  • 文件直写 / REST API 双模式
  • 自动创建结构化笔记
  • 支持 Vault 目录自定义

微信左侧栏（软件实时捕获）

左图为被监控的微信窗口；右图是软件从侧边栏截图中检测出的红点，黄色框标出位置与坐标，随后自动计算点击坐标切换到对应联系人。
🎯

模板匹配（优先）

  • 首次运行自动截取红点模板
  • cv2.matchTemplate 精准定位
  • 多尺度匹配（0.8x~1.2x）适应 DPI
  • NMS 去重避免重复框选
🎨

HSV 6特征（兜底）

  • 颜色：#FA5151 微信标准红
  • 面积 100~3000 px²
  • 圆形度 > 0.5 排除图标
  • 内部白色数字校验
🪟

后台无感模式

  • 最小化后移入虚拟屏幕（-10000,0）
  • PrintWindow 强制渲染保活
  • SendMessageW 后台点击，绝不抢焦点
  • 你点任务栏图标即可恢复窗口
Quick Start

快速开始

三步搞定，开机即用

准备环境

Windows 10/11 + Python 3.10+，桌面版微信 4.x 已登录，阿里云千问 API Key。

安装启动

双击 start.bat 一键安装依赖并启动；或手动执行 python ui_app.py。

配置运行

在设置页填入 LLM API Key，点击「开始监控」，最小化微信即可后台运行。

# 方式一：一键启动（推荐）
双击 start.bat

# 方式二：手动
pip install -r requirements.txt
pip install pywin32 psutil
python ui_app.py
💡 首次启动需初始化 PaddleOCR 模型与 LLM 客户端，约 5~10 秒，界面会分步显示加载进度，属正常现象。

FAQ

常见问题

启动提示「未找到微信窗口」怎么办？
  • 确保微信已登录且窗口显示在桌面（非最小化）
  • 微信窗口标题不能包含「AI」或「助手」（会与本程序窗口混淆）
  • 多显示器环境下，确保微信在主显示器
OCR 识别不到文字？
  • 检查微信窗口是否被其他窗口遮挡
  • 在设置页调整 OCR 缩放比例（建议 0.5~0.85）
  • 使用「窗口校准」手动框选聊天区域
  • 查看系统 DPI 缩放（推荐 100% 或 125%）
红点检测不到未读消息？
  • 查看 debug/ 目录下的调试截图（sidebar_capture.png / debug_no_reddot.png）
  • 确认红点颜色为标准微信红 #FA5151
  • 调整 red_min_area / red_max_area 参数
  • 首次运行会自动截取红点模板，多运行几次精度会提升
最小化后识别不到未读消息？
  • 确认配置中 minimize_mode: offscreen（屏幕外保活模式）
  • 该模式下微信会被移到虚拟屏幕（-10000,0）保持渲染，点任务栏图标即可恢复
  • 若仍失败，可尝试「👁 显示微信」按钮手动恢复后再监控
自动回复没有生效？
  • 确认已配置 LLM API Key 且模型名正确
  • 确认 auto_reply.enabled: true
  • 检查联系人是否被黑名单过滤
  • 查看「日志」标签页中回复失败的具体原因
