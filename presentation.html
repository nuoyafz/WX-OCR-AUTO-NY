03 / 08

核心功能

四大核心能力

实时截图 OCR 识别

PaddleOCR 引擎实时识别微信聊天区域文字，自动区分自己/对方气泡，增量检测画面变化，最小化状态下也能通过 PrintWindow + UIA 无渲染监控

AI 智能回复

接入大语言模型 (通义千问)，支持角色设定、对话上下文管理、RAG 本地知识库检索增强，可预览确认后发送或全自动回复

红点未读监控

CNN 红点分类器 + HSV 模板匹配双引擎，自动检测微信侧边栏未读红点，精准点击切换联系人，像素级验证确保切换成功

知识库归档

SQLite 本地持久化 + Obsidian 笔记同步，消息情感分析 + 紧急度自动分级，语义向量去重，重要消息自动标记归档

05 / 08

技术创新

五个关键技术突破

01

CNN 红点分类器替代传统 HSV 模板匹配

轻量级深度学习模型消除红色头像、红包图标等误触发，识别准确率大幅提升

02

Windows UI Automation 无渲染未读监控

最小化/屏幕外状态下通过无障碍 API 直接读取微信侧边栏未读信息，无需恢复窗口

03

自适应点击优化器

像素级红点验证 + 智能 Y 偏移微调 + 聊天区直方图变化检测，确保点击切换零失误

04

语义向量去重 + RAG 本地知识库

sentence-transformers 语义级去重，ChromaDB 向量检索增强 LLM 回复上下文

05

三阶段情感分析 + 紧急度自动分级

规则引擎 → 统计模型 → LLM 兜底，高效准确的消息情感和紧急度判断
